## Decisiones y supuestos

- Se elige una única plantilla server más un componente client de tabs porque las siete rutas comparten exactamente el contrato de datos y así se evita mantener siete implementaciones divergentes.
- La resolución usa `createDrupalClient()` y no UUIDs. La consulta local confirmó que las siete entidades publicadas existen con los nombres esperados, pero `path.alias` llega nulo; por eso el servicio intenta alias y aplica un fallback documentado de slug normalizado del título. Si el endpoint comienza a entregar alias, ese valor tiene prioridad.
- Las noticias se cargan con `getNews()` en el mismo `Promise.all` que facultad/oferta, pero no se filtran por facultad, tal como requiere la tarea.
- No se agregan tests porque el repositorio no declara framework de pruebas; la validación aprobada es lint y build.
